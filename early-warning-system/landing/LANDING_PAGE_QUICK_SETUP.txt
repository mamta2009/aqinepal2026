HOW TO INTEGRATE (CHOOSE ONE)
═════════════════════════════════════════════════════════════════════════════════

OPTION 1: LOCAL DEVELOPMENT (FASTEST)
─────────────────────────────────────

1. Extract early-warning-system.zip
   unzip early-warning-system.zip
   cd early-warning-system/frontend

2. Copy landing.html here
   cp landing.html .

3. Open in browser
   open landing.html
   # or
   start landing.html  (Windows)

4. Click "Enter Dashboard" → goes to index.html

DONE! ✅


OPTION 2: WITH FASTAPI BACKEND
──────────────────────────────

1. Copy landing.html to frontend/ folder

2. Update backend/main.py:

   Add this import:
   from fastapi.staticfiles import StaticFiles

   Add this line after app creation:
   app.mount("/frontend", StaticFiles(directory="frontend", html=True), name="frontend")

3. Start backend:
   python backend/main.py

4. Open in browser:
   http://localhost:8000/frontend/landing.html

5. Click "Enter Dashboard" → goes to index.html


OPTION 3: RENDER DEPLOYMENT (PRODUCTION)
─────────────────────────────────────────

1. Copy landing.html to frontend/ folder

2. Push to GitHub:
   git add landing.html
   git commit -m "Add landing page"
   git push

3. Render auto-deploys

4. Visit your Render URL:
   https://your-app.onrender.com/frontend/landing.html

5. Everything works! ✅
